# 0.1.2 软件验证报告

结论：本地 Windows LaserMaker 2.1.7.2 的几何、MCP 和原生工程短流程核验通过；尚未进行实物试切。两小时连续工作负载测试按要求暂缓，没有把不同轮次累加为通过。

- 自动化测试：91 项通过，2 项可选现场测试跳过。命令：`python -m pytest -q`。
- 原创工具站：54 件、987 个对象，4 张 600 × 400 mm 产品排板及独立试切片，共 5 个原生项目，均实际导入、读回尺寸、设置工艺、保存、关闭并按准确路径重新打开，工艺值保留。
- 独立图纸对照：最大偏差约 0.004945 mm，120 组穿板榫槽匹配；抽屉 0–80 mm 连续扫掠检查未发现与固定木板的正体积干涉。几何检查不包含五金、载荷和抗倾覆。
- 精细编辑：移动、旋转、非均匀缩放、镜像、节点、复制、阵列、对齐、分布、偏移、布尔及明确源恢复；各批请求重放与新 MCP 进程恢复通过。
- 边界：真实 stdio MCP 达到 20,000 对象，成功读回和预检；第 20,001 对象与 1001 操作超限请求均拒绝，已核对版本和文件不变。
- 宿主：Codex CLI 0.164.0、Claude Code 2.1.310、Kimi Code 2.3.2、DeepSeek Harness 0.2.1-rc.2 / Cordis 4.0.5，四种加载器均发现 17 个工具；Codex／DeepSeek 作原生工具调用，Claude／Kimi 使用加载器解析出的 stdio 配置实际调用。
- 跨宿主：Codex 创建第 1 版，DeepSeek 复制到第 2 版并重放，Claude／Kimi 接续到第 3／4 版。
- 公开分发候选包：6 个 ZIP 的 CRC 检查通过；905 个运行时文件与测试构建逐字节一致。解压到含中文及空格的新目录后，公开工程的桌面绑定已移除，仍可通过新 MCP 进程重开原生文件、核对 570×330 mm 及三色工艺并关闭，原生 SHA-256 保持不变。
- 修复：圆弧镜像与非均匀缩放保留精确椭圆弧；装配正 Y 向上到 SVG 向下的转换；过期原生验收记录核对；中断绘制后的原事务重放审计。

原生尺寸读回是对软件文件的核验，不代表机器精度。几何计算容差 0.01 mm，界面尺寸读回容差 0.05 mm。图层速度和功率是软件落盘测试值，不是生产建议；未发送或启动机器。

模型账户对话端到端、材料和切缝、五金实配、强度、机器幅面／控制器、路径排序及实机仿真仍未验证，`manufacturing_ready=false`。未知弹窗会使驱动停止并保留状态；本次“自动恢复”中断在保留旧记录、确认现场状态后以新受控项目继续，未盲目重放 GUI 操作。

公开副本仅包含当前设计和筛选后的证据；私人原作品、失败会话、账户缓存和原始宿主日志保留在本地。公开 JSON 中的本机路径已转换为相对位置，并移除桌面 PID 绑定，使用时先 `resume_project`，再按实际原生路径 `reload_and_verify` 获取新绑定。

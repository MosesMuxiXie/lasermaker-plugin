# 资料与核实记录

调查日期：2026-10-26。当前本机基准为 Windows LaserMaker2.1.7.2。

## 坦克外形资料与原创绘制

- [田宫 M4A3 75 mm，35122](https://www.tamiya.com/japan/products/35122/index.html)：官方商品页说明方正焊接车体与圆形铸造炮塔，标注模型长 172 mm、宽 78 mm。采用这种外形组合；本例自行设计为 198 × 90 × 78 mm，并非照搬比例。
- [田宫 M4A3 遥控模型，48217](https://www.tamiya.com/english/products/48217/index.html)：核对履带、车体与炮塔的模型分件概念，未采用其驱动机构。
- [田宫 M1A2 SEP TUSK II，35326](https://www.tamiya.com/english/products/35326/index.html)：对比现代坦克模型的外形和分件；官方模型尺寸 280 × 127 mm。本轮未生成 M1A2 切割图。
- [英国坦克博物馆 Tiger I](https://tankmuseum.org/tank-nuts/tank-collection/tiger-i/?tpage=1)：历史车型参考，未将其武器或装甲数据转为制作图。
- [田宫 M51 官方组装说明 PDF](https://www.tamiya.com/cms/english/rc/rcmanual/56031sherman.pdf)：检索并确认是 24 页官方图解手册；当前网页工具未返回可查看的截图，因此不声称逐页核对，也未复制该手册插图或完整零件图。

市售模型图和历史图只用于外观比较。二维轮廓、榫槽、炮塔叠层、垫块、装饰轮件与装配矩阵均由本项目原创生成，不把市售塑料模型组装图当作现成激光切割图。三维 STL 来自同一份可编辑切割源。

## 官方资料

- [LaserMaker 新手上路](https://www.lasermaker.com.cn/learning-101.php)：已读取绘图、布尔、节点、尺寸、材料测试、仿真等文字说明。
- [官方知识库](https://www.lasermaker.com.cn/forum.php?fid=22&mod=forumdisplay)：已确认材料厚度、导入矢量尺寸问题等文档入口；部分正文需要动态加载，不能据入口标题声称已阅读全文。
- [官方 FAQ](https://software.lasermaker.com.cn/faq-2)：核实软件版本／授权、DSP与GRBL支持范围；设备支持仍以具体型号和当前官方说明为准。
- [雷宇教育视频](https://edu.thunderlaser.cn/video)：安装、绘图、切割／雕刻工艺的官方视频目录。
- [台湾官方视频目录](https://www.thunderlaser.tw/lasermaker-video)：已打开目录，确认06同色选择、08复制、10雕刻参数、11切割参数、12混合加工、14顺序、16传输、17控制、18连接的入口。
- [视频14：加工顺序](https://www.thunderlaser.tw/lasermaker/lasermaker-video-14.html)：已读取页面并检查播放器；嵌入的优酷视频因 Cookie 限制未能播放。**尚未逐帧观看，没有可声称已核实的时间点。** 后续验证必须记录实际播放证据，不能补造时间戳。

## 用户补充的课程与案例

- [学校雷切课程](https://sites.google.com/mtm.kh.edu.tw/mtmlasermaker/%E9%A6%96%E9%A0%81)：已读取文字课程，包括精确编辑、闭合曲线、SVG导入、图层及装配项目；引用的是1.5系列，旧快捷键和菜单位置须与2.1.7.2复核。
- [Scribd 手册](https://www.scribd.com/document/820311479/lasermakertutorial)：公开页面可读取入门内容和目录，正文标注V1.5.48。仅作概念交叉核对，没有绕过登录／付费限制，也未复制整本手册。
- [DFRobot：一台聊城机的换“芯”之旅](https://mc.dfrobot.com.cn/article-310413.html)：已通过浏览器读取，属于2021年换控制板案例，涉及4060／60W及特定睿达板卡。仅作兼容性历史背景；关闭水保护、开盖保护等步骤不纳入本教程和插件。内嵌短视频也不能代替通用软件教程。

## 知乎、CSDN、Reddit 检索

检索过 LaserMaker、激光建模、雷宇、使用教程与对应站点限定组合。

- 知乎：当前检索结果未找到足够可靠、可直接核对2.1.7.2操作的专项教程；相关激光设备安装讨论不作软件操作依据。

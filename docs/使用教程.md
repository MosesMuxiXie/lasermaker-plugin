# LaserMaker 精简使用教程

适用基准：Windows 简体中文版 V2.1.7.2。下文的“打印”指激光描线／雕刻，不是 FDM 打印。

## 1. 新建与 1:1 导入

新建图纸后设置合适的排版范围，单位使用 mm。导入矢量文件后先测量已知尺寸，不要选择“适应页面”作为加工比例。公开工具站样例的排板为 600×400 mm，第一张实际图形范围为 588×372 mm；组装成品为 270×210×280 mm。排板大小、图形范围与成品外形是三个不同尺寸，各张的导入目标见其 delivery.json 和预检报告。

本插件的 SVG 已处理本机 2.1.7.2 把坐标解释为 CSS 像素的问题：坐标采用 96/25.4 倍、物理宽高仍使用 mm。若导入尺寸不符，应核对导入配置与目标尺寸，不能把图形直接拉满页面。

## 2. 精确编辑

选中对象后使用上方 X、Y、宽、高和旋转数值。注意“原点”锚点会影响 X/Y 含义；先明确锚点，再设置位置。等比锁定适合整体缩放，插槽校准应单独改尺寸，避免连带缩放整个产品。

绘图工具用于直线、曲线、矩形、圆和文字；节点编辑用于修改局部轮廓；布尔并／差／交处理组合形状；阵列、对齐、镜像用于重复结构。通过插件编辑时使用稳定对象 ID，所有源坐标为 mm。

## 3. 文字与轮廓

加工交付使用矢量路径文字，避免换机缺字或字体替换。插件的 text 操作需要明确字体文件；缺字会报错。保留材料的轮廓必须闭合，描线允许开放路径。删除重复切割边，检查自交、狭窄连接和悬空保留件。

## 4. 图层与工艺

样例黑色用于切割，红色用于描线；默认黄色和蓝色对应浅雕、深雕，但必须打开“加工参数”核对实际工艺。描线是沿线走刀，填充雕刻是区域扫描，二者不能只凭颜色判断。

双击图层参数，核对工艺、速度和最大功率；切割／描线另有转角功率，浅雕／深雕参数框没有该字段。本机速度界面单位为 mm/s，不能直接套用其他软件的 mm/min。教材数值、软件预设和插件测试值不代表当前机器的可用生产参数。

## 5. 板厚、切缝与试切

测量实际板厚，先切独立插槽试切片。样例提供 2.7—3.3 mm 七档槽宽，选择可徒手装入且稳定的档位。切缝补偿须来自实际试切，不能猜测一个固定值。

板厚变化还会影响榫头长度、底面齐平和装配关系。插件 set_material 只更新材料声明，不能代替这些结构调整。

## 6. 排序与仿真

先描线／雕刻，再切内部孔槽，最后切外轮廓，避免零件先脱落后移位。仿真用于检查走刀与遗漏，不是实际切透或装配强度的证明。

本机路径规划曾呈灰色；若无法核实内外顺序，使用分阶段图纸，并在报告中保留“未验证”。不要把 SVG 文件中的路径排列当作机器一定执行的顺序。

**阶段之间还要配准。** 本机导入会把选区自动居中，分别导入阶段 SVG 可能改变各阶段的位置，只有“板材不动”并不足够。优先在同一原生工程保留坐标后分阶段输出；另行导入时，固定中心锚点，记录完整图形的中心，参考样例 `stage-registration.json` 的源坐标中心差，确认界面 Y 方向后重新定位。源 SVG 的 Y 向下；界面 Y 若向上，ΔY 需反向。逐一核对共同基准、实际原点和轮廓位置；不能把这些源坐标差直接当作机床坐标。空阶段跳过。

## 7. 保存与重新打开

另存为新的 .lcpx；明确检查目录和文件名。再从磁盘重新打开该路径，复核尺寸、图层、工艺及速度／功率。标签改名、画面正确都不能代替实际文件检查。

插件按“保存—重开核验—检查点—导出”完成交付；源文件发生修改后，旧原生工程不能再当作当前版本交付。

## 8. 现场加工与装配

现场人员依据设备说明确认材料、工作幅面、焦距、气辅、冷却／排烟和保护功能，再按实际机器试切。插件不执行发送或启动。

灵感工作舱由六个零件组成，名义成品 130×110×125 mm。先试装、核对榫头与底面齐平，再按装配说明固定。软件检查通过不等于已经完成实物站立与强度测试。

进一步操作与出处见[资料记录](资料来源.md)和[接口说明](接口与恢复.md)。
